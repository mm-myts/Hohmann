This is a project of mine I made in pursuit of learning more about orbital mechanics. 
It functions by recieving two variables:
  - the strarting altitude of a satelite
  - the finishing altitude of a satelite

Its purpose is to visualise the whole manoeuvre in a simple image and also show how the
individual burns change the orbit of a spacecraft.

Features (so far):
 - Visualiser of the orbital change
 - Graph of the change of speed relative to time

Necessary python libraries:
 - scipy
 - numpy
 - matplotlib
